Sobre este sitio web

El sitio web de Müchi Café tiene principalmente una finalidad informativa. A través de este sitio se proporciona información sobre el establecimiento, incluyendo el menú, bebidas, horarios, ubicación, redes sociales y programa de fidelidad.

El sitio web de Müchi Café no cuenta con un formulario propio para que las personas usuarias se registren directamente en el programa de fidelidad.

Cuando una persona selecciona la opción para obtener la tarjeta de fidelidad, es dirigida a una plataforma externa proporcionada por Woncards, donde se realiza el proceso correspondiente para la creación y gestión de la tarjeta digital.

Datos personales

El sitio web de Müchi Café no solicita directamente datos personales para la creación de la tarjeta de fidelidad.

Los datos personales que sean proporcionados durante el registro o utilización del programa de fidelidad serán tratados de acuerdo con las funciones y condiciones aplicables a dicho servicio.

Dependiendo de la configuración del programa de fidelidad, podrán tratarse datos como nombre, correo electrónico, número telefónico u otros datos necesarios para administrar dicho programa.

Müchi Café procurará que los datos personales tratados sean adecuados, relevantes y necesarios para las finalidades correspondientes.

Finalidades del tratamiento

En caso de que Müchi Café tenga acceso a datos personales relacionados con el programa de fidelidad, estos podrán ser tratados para las siguientes finalidades:

  • Administrar y operar el programa de fidelidad de Müchi Café.

  • Identificar a las personas participantes del programa.

  • Registrar y administrar beneficios, recompensas, promociones o visitas relacionadas con el programa.

  • Atender solicitudes relacionadas con la tarjeta de fidelidad.

  • Mantener y administrar la relación con las personas participantes.

  • Cumplir con las obligaciones legales que resulten aplicables.

  • Los datos personales no serán utilizados para finalidades distintas de aquellas informadas en el presente Aviso de Privacidad, salvo que resulte aplicable una nueva finalidad y se proporcione la información correspondiente conforme a la legislación aplicable.

    • Plataforma de terceros

    El registro y funcionamiento de la tarjeta de fidelidad se realiza mediante una plataforma externa proporcionada por Woncards.

    Al acceder a dicha plataforma, la persona usuaria podrá estar sujeta a los términos, condiciones, avisos de privacidad y demás políticas aplicables de Woncards.
